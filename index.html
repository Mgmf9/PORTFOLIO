In developmentAgents · Python / Node

FOMO: market intelligence for crypto

FOMO stands for Financial Operations & Market Intelligence. The goal is one assistant that watches the market, ranks opportunities and flags portfolio risk. I designed it as specialized agents coordinated by a central core, built in five phases from an MVP to real exchange integration.

Market data→Specialized agents→FOMO Core→FOMO Score + dashboard→Risk Gate→Execution (off by default)

Two rules I set from day one: no real order runs by default, and a Risk Gate sits in front of any execution. Anything that is only cosmetic gets labeled as such, so the interface never claims more than the system does.

  • multi-agent design
  • risk controls
  • dashboard
  • roadmap in 5 phases
LiveLLM · Node · Render

Study notebook that writes its own lessons

A study site built from short modules, where answering a question unlocks the next one. You paste a summary of any subject and the model turns it into modules and questions in the same format as the original. A language switch renders everything in Italian, Portuguese or the original text.

It started as a single subject, an Italian workbook on safety in school laboratories, and is being opened up to many subjects. A real student uses it on phone, tablet and laptop, which keeps me honest about layout and speed.

  • Groq · gpt-oss-120b
  • Node backend on Render
  • GitHub Pages frontend
  • dark / light theme
  • IT · PT · original

In developmentGame AI · Luau

Abyss Crew: Deep Salvage

A cooperative diving and salvage game in Roblox Studio. A leviathan hunts by light and noise: it investigates first and keeps updating its target while it does, then switches to the hunt. Two players raise salvage together with a crane, and a short boost helps them escape. In first person the fog gets thicker the deeper you dive.

Light / noise→Investigate (target keeps updating)→Hunt

I draft code with AI assistants, then run everything in Studio and fix what breaks: syntax errors, a logic bug from duplicated blocks, and a loader that left model parts falling apart. Saves use a DataStore wrapper that survives the store being unavailable.

  • Luau
  • server + client scripts
  • DataStore with fallback
  • TweenService
  • Roblox Studio

How I approach AI work

Put the model where it earns its cost

Not every decision needs an LLM. In the moderation bot, the model is reserved for ambiguous terms.

Gate every real-world action

Agents suggest; a separate check approves. FOMO has no live execution until that gate exists and has been tested.

Say what is not done

If a feature is a placeholder, it is labeled as one. I would rather show a short honest list than a long impressive one.
